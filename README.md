## 🚀 Atividades Desenvolvidas

Cada pasta representa um conjunto de exercícios com um foco específico no aprendizado:

* **Atividade Prática 01:** Introdução aos fundamentos da linguagem Python. Esta atividade foca na declaração de variáveis, operações aritméticas básicas, manipulação de diferentes tipos de dados e a captura de entradas do usuário.
    * `saudacao.py`: O clássico "Olá, Mundo!", demonstrando o uso da função `print()`.
    * `calc_soma.py`: Script que realiza a soma de dois números pré-definidos para introduzir o conceito de variáveis.
    * `cal_volume.py`: Calcula o volume de uma caixa com dimensões fixas, praticando a multiplicação entre variáveis.
    * `cal_preco_total.py`: Simula o cálculo do valor total de uma compra.
    * `calc_num_inteiro.py`: Programa que lê quatro valores do teclado e aplica uma fórmula, introduzindo a função `input()` para interatividade.

* **Atividade Prática 02:** Foco na resolução de problemas práticos utilizando operações aritméticas e formatação de saídas para cenários do cotidiano.
    * `conversor_moeda.py`: Converte um valor em Reais para Dólares e Euros.
    * `calc_desconto.py`: Calcula o valor de um desconto percentual e o preço final de um produto.
    * `calc_media_escolar.py`: Calcula a média aritmética a partir de três notas.
    * `calc_combustivel.py`: Determina o consumo médio de um veículo (km/l).
    * `calc_soma_usario.py`: Soma dois valores inteiros que podem ser informados pelo usuário.
    * `calc_salario_hora.py`: Calcula o salário de um funcionário com base nas horas trabalhadas e no valor por hora.

* **Atividade Prática 03:** Aprofundamento no uso de estruturas de decisão (`if`, `elif`, `else`) para criar programas que respondem a diferentes condições e entradas do usuário.
    * `calculadora_imc.py`: Solicita peso e altura, calcula o IMC e classifica o resultado.
    * `calculadora_media_ponderada.py`: Sistema completo de avaliação escolar que calcula a média ponderada e determina a situação do aluno (aprovado, reprovado ou em exame).
    * `classificador_idade.py`: Classifica o usuário em "Criança", "Adolescente", "Adulto" ou "Idoso".
    * `verificador_ano_bissexto.py`: Implementa a lógica completa para determinar se um ano é bissexto.
    * `calculadora_comissao.py`: Calcula o salário total de um vendedor, somando uma comissão sobre as vendas.
    * `conversor_temperatura.py`: Converte temperaturas entre Celsius, Fahrenheit e Kelvin.

* **Atividade Prática 04:** Foco em laços de repetição (`while`), validação de entradas e tratamento de exceções (`try`/`except`) para criar programas mais robustos e interativos.
    * `calculadora_segura.py`: Uma calculadora que lida com erros de entrada não numérica, operações inválidas e divisão por zero.
    * `contador_par_impar.py`: Um script interativo que conta números pares e ímpares inseridos pelo usuário em um loop.
    * `media_turma.py`: Um sistema para registrar notas válidas (0 a 10) e calcular a média da turma.
    * `validador_senha.py`: Um verificador que exige que o usuário digite uma senha que atenda a critérios de força (comprimento e presença de números).

* **Atividade Prática 05:** Introdução à criação de **funções** para modularizar e reutilizar código, além de manipulação de strings e uso de bibliotecas nativas como `datetime`.
    * `calculadora_de_gorjetas.py`: Função que calcula o valor da gorjeta com base no total da conta e na porcentagem desejada.
    * `calculadora_de_desconto.py`: Função que recebe um preço e um percentual para calcular o valor final com desconto.
    * `verificador_de_palindromo.py`: Implementa uma função que limpa uma string e verifica se ela é um palíndromo.
    * `calculadora_de_idade_dias.py`: Utiliza o módulo `datetime` para calcular a idade aproximada de uma pessoa em dias a partir do ano de nascimento.

* **Atividade Prática 06:** Foco no consumo de **APIs externas** para buscar dados na internet e na geração de dados aleatórios.
    * `consulta_cep.py`: Utiliza a API `ViaCEP` para buscar e exibir um endereço a partir de um CEP informado.
    * `consulta_cotacao.py`: Consome a `AwesomeAPI` para obter a cotação de moedas em tempo real.
    * `gerador_de_perfil.py`: Usa a API `Random User Generator` para criar e exibir um perfil de usuário fictício.
    * `gerador_de_senha.py`: Utiliza os módulos `random` e `string` para gerar uma senha aleatória segura com o tamanho definido pelo usuário.

* **Atividade Prática 07:** Foco em **manipulação de arquivos locais**, realizando leitura e escrita em formatos de dados estruturados amplamente utilizados.
    * `ler_csv.py` e `escrever_CSV.py`: Scripts para ler dados de um arquivo `.csv` e para criar um novo arquivo `.csv` a partir de uma estrutura de dados.
    * `ler_escrever_json.py`: Demonstra a leitura de um arquivo `.json` existente e a escrita de um novo.
    * `processar_logs.py`: Exemplo prático que lê um arquivo de logs em formato `.csv` e realiza um cálculo para sumarizar as informações.

* **Atividade Prática 08:** Projeto de introdução ao **Machine Learning**, aplicando os conhecimentos de Python e bibliotecas de dados para construir e avaliar um modelo preditivo.
    * `modelo_ca.py`: Script que utiliza **Pandas** para carregar e preparar dados, e **Scikit-learn** para treinar um modelo de `RandomForestClassifier`. O programa treina o modelo, faz previsões e avalia sua performance com métricas como Acurácia, Recall, F1-Score e AUC.

## ⚙️ Como Executar

Para testar qualquer uma das atividades, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone git@github.com:Alessandro-krepk/EscolaDaNnvemIA175.git
    cd EscolaDaNuvemIA175
    ```

2.  **Crie e ative um ambiente virtual:**
    ```bash
    # Criar o ambiente
    python3 -m venv venv

    # Ativar (Linux/macOS)
    source venv/bin/activate
    ```

3.  **Instale as dependências:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Execute um script:**
    Navegue até a pasta da atividade desejada e execute o arquivo Python.
    ```bash
    cd Atividade_pratica08
    python modelo_ca.py
    ```
